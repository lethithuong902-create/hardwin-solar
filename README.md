# Hardwin Solar

Mô phỏng 3D Hệ Mặt Trời — hệ sinh thái **Hardwin**.

## Chạy local
Mở `index.html` bằng trình duyệt.

## Deploy (Vercel)
Kết nối repo này với Vercel. Mỗi lần sửa code trên GitHub, web tự cập nhật.

## Tính năng
- Mặt Trời, 8 hành tinh, vành đai Sao Thổ, Mặt Trăng
- Kéo xoay, cuộn phóng to, nhấp hành tinh xem thông tin
- Nhiệm vụ khám phá 9/9 thiên thể
